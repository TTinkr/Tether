# Contributing

Use a feature branch and describe the behavior changed, the reason and how it was tested. Keep patches scoped. Preserve transcript fidelity, local inference boundaries and consent checks.

Run the commands in README. Add regression coverage for capture, cancellation, recovery or delivery changes. Synthetic tests do not replace attended microphone and editor testing when those behaviors change. Report the exact app version, OS, model and destination editor without sharing private text.

Use fictional fixtures and neutral examples. Do not commit recordings, credentials, private paths, machine-specific signing settings or internal agent history. Keep third-party notices intact. Contributions to the app source are under the MIT license; do not submit material you cannot license.
